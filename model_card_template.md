# Model Card

For additional information see the Model Card paper: https://arxiv.org/pdf/1810.03993.pdf

## Model Details
- This model is created for the ML Machine learning DevOps project part two
- This model was created and maintained by Jesse Carter a student at Western Governors University
- Created on 1/08/2025
- Version 1.0
- Using the starter code, I wrote a machine learning model that trains on the clean data and saves the model. I completed any function that has been started
- Wrote unit tests for at least 3 functions in the model code
- Wrote a function that outputs the performance of the model on slices of the data


## Intended Use
- This project is intended to show an example of deploying a Scalable ML Pipeline in Production
- Predict whether income exceeds $50K/yr based on census data


## Factors
- This data is very old as it was collected in 1994, as such, it should only be used for instructional purposes
- It would also be advisable to consider the sampling groups as well

## Metrics
There were three metrics used in this project; fbeta_score, precision_score and recall_score.

## Evaluation Data
There was only 20% of the original dataset for evaluation purposes of the model.

## Training Data
There was the final 80% of the original dataset for the training purposes of the model.

## Quantitative Analyses
The model performance is measured based on three metrics: fbeta score, precision score and recall score.
